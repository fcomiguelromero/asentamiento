# Asentamiento

Juego de estrategia en tiempo real en perspectiva isométrica, para navegador. Parodia en clave de humor: un poblado chabolista se instala en un descampado a las afueras de la ciudad y el Ayuntamiento quiere desalojarlo.

Hecho con HTML, CSS y JavaScript sobre canvas, sin librerías. Todos los gráficos y sonidos se generan por código.

## Jugar

Abre `index.html` en el navegador, o la versión publicada en GitHub Pages.

## Versión 0.1

- Unidades: chatarrero, echadora de la buenaventura y navajero.
- Edificios: chabola principal, chabola (cartón, uralita y ladrillo) y Taberna El Pincho.
- Rival: el Ayuntamiento, con policías locales e inspectores de Urbanismo.
- Niebla de guerra, minimapa, atajos de teclado y tres niveles de dificultad.
